Random = logique continue d’avant. BFS = exploration par couches. DFS = exploration en profondeur. Les réglages ci-dessous s’appliquent en direct sans relancer le backend.

Réglages en direct

Le bouton Simulation ouvre la démo dans une autre page via le backend, donc tu n’as plus besoin d’ouvrir un fichier HTML à la main.

Commandes manuelles

Flèches clavier = pilotage maintenu. Espace = stop. Manette : stick gauche pour bouger, A stop, Start init robot, X Random, Y BFS, B DFS, LB stop exploration. En manuel, le backend sort du mode exploration.
